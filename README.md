# Patakder

Patakder is a planned web application that helps residential contractors create floor plans, edit them with simple CAD-style tools, and explore the same design through connected 2D, 3D, exterior, and walkthrough views.

The first user is a contractor with practical construction experience who wants to plan and explain house layouts without learning traditional CAD commands.

The confirmed first-release scope targets laptop/desktop use and supports both single-storey and multi-storey houses, including connected floors and stairs.

## Product documentation

- [Product requirements document](docs/PRD.md): functionality, user journeys, Laravel architecture, data requirements, acceptance criteria, and delivery phases.

## Project status

Product planning and documentation. Application development has not started.

Laravel is the selected web application framework. The PRD proposes a browser-based drawing and visualization layer alongside Laravel; the detailed implementation choices will be validated before development.

Plans produced by the proposed application are concept designs for discussion and professional review. Construction documentation and engineering approval are separate deliverables.
